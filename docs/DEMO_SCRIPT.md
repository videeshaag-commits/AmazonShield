# 3-minute demo outline

0:00-0:20 — Problem
"People receive convincing phishing messages every day and often cannot
tell what is dangerous."

0:20-0:40 — Solution
"AmazonShield uses an AI agent to investigate a suspicious message and
explain the warning signs instead of only returning a yes/no answer."

0:40-1:40 — Live demo
Paste a realistic suspicious message.
Show the risk level, indicators and safe actions.

1:40-2:20 — AWS/AI architecture
Explain that the Strands agent orchestrates the investigation and the
application exposes it through a FastAPI endpoint.

2:20-2:50 — Impact
Explain how the tool can help students, families and organizations
recognize social-engineering attempts.

2:50-3:00 — Close
Show the working UI and repository.
